One code review comment, one line, at most 140 characters: it approves a pull request while carrying quiet existential dread. The reviewer signs off, the tests pass, and the dread is that the next reviewer will be a model approving the PR that replaces the human.

## Run it

```sh
python3 main.py
```

This writes the line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` when set, otherwise `./output`).
